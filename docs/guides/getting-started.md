# Getting Started

Welcome to the project! This guide will help you set up your local development environment.

## Prerequisites

- Node.js 18+
- npm or pnpm
- Git

## Quick Start

```bash
git clone <repo-url>
cd <project>
npm install
npm run dev
```

## Configuration

Copy the environment template and adjust values for your setup:

```bash
cp .env.template .env.local
```

See the [configuration reference](../references/config-vars.md) for details.
